# Security Policy

## Supported Versions

The project is not yet very mature so it’s being kept in beta 0.x.x in case any breaking changes need to be made. 

| Version | Supported          |
| ------- | ------------------ |
| 0.latest | :white_check_mark: |

## Reporting a Vulnerability

Please head to the “Security and quality” tab on the GitHub repository to privately disclose any vulnerabilities you’ve found, so that we can fix the issue before the issue is made public. If possible submit a Proof-of-Exploit script and patch recommendation. The number of vulnerabilities that can be reported is currently limited to 10 per day. 

If you are unable or unwilling to use GitHub or something is broken, please send a maintainer an email or DM on social media.
